# Security

ElderGuard is a student prototype tested on demo data only. It has not had a security review and should not hold real health records.

If you find a vulnerability, please report it privately through GitHub's "Report a vulnerability" option on the Security tab rather than a public issue. I will reply within a week.

Known gaps are listed under "Known limits" in the README. The demo accounts and their shared password exist only in the seed script and must never be used in a real deployment.
